# Constitution 360° — India's Constitutional Second Brain

An interactive static learning workspace for the Indian Constitution, UGC NET/JRF and Public Administration.

## Current modules
- Dashboard and suggested study roadmap
- All constitutional Part headings, including inserted Parts and repealed Part VII clearly labelled
- High-yield Article memory bank with plain-language summaries, mnemonics, exam links and governance examples
- Clickable SVG mind maps: Fundamental Rights, DPSPs, Union Government, Federalism, Emergencies, Services and Accountability
- Twelve Schedules quick-reference cards
- Important constitutional amendments timeline
- Landmark case-law stories with doctrines and Public Administration connections
- Memory tricks, active-recall flashcards, MCQ quiz and browser-based progress tracker
- Links to the official Legislative Department documents, full-text Article directory, India Code and Supreme Court

## Publish with GitHub Pages
1. Open repository Settings → Pages.
2. Under Build and deployment, select Deploy from a branch.
3. Select branch `main` and folder `/(root)`, then Save.
4. After deployment, visit https://thizforyou-cyber.github.io/constitution360/.

## Full text and accuracy
The site's Article cards are learning summaries, not verbatim constitutional text. Use the Legislative Department's Documents page for the latest official edition and amendment material. The Constitution of India reader provides a browsable Article directory and individual Article pages. A linked 2024 official PDF is included as a convenient full-text reference; check the edition date and official documents page for later editions. Verify exact clauses, amendments, commencement conditions and case holdings before exam or legal use.
