# Constitution 360° — India's Constitutional Second Brain

A responsive static learning workspace for the Indian Constitution, UGC NET/JRF and Public Administration.

## Included
- Constitution map by Parts and a searchable starter Article library
- Plain-language explanations, memory hooks and governance examples
- Landmark case-law stories
- Constitution × Public Administration connections
- Browser-based active-recall review queue and quiz arena
- Links to primary and trusted sources

## Publish with GitHub Pages
1. Open repository Settings → Pages.
2. Under Build and deployment, select Deploy from a branch.
3. Select branch `main` and folder `/(root)`, then Save.
4. After deployment, visit https://thizforyou-cyber.github.io/constitution360/.

## Accuracy note
This is an educational revision aid, not legal advice. Article descriptions are paraphrases, not authoritative constitutional wording. Verify exact text, amendments, current legal position and detailed case holdings from primary sources.
